# Kunskapen

Allt i den här mappen (utom den här filen) är det agenten får påstå som fakta. Filerna läses i
namnordning vid varje körning. Skriv vanlig Markdown.

- `verksamhet.md`: namn, adresser, kontakt, öppettider, vad ni erbjuder, priser, villkor och
  länkar. Första rubriken blir verksamhetens namn i agentens instruktioner.
- `tjanst.md`: förmågekartan för er tjänst eller app, om ni har en. Vad kunden kan göra själv,
  var och hur, och vad bara personalen kan göra. Skapas ur koden med skillen och godkänns av en
  människa.
- Fler filer går bra, till exempel `vanliga-fragor.md` eller `priser.md`.

Det som inte är säkert skrivs som [[FRÅGA: ...]]. Då skriver agenten en fråga till granskaren i
stället för att gissa.

Skriv aldrig personuppgifter, lösenord eller nycklar här. Filerna ligger i repot.
